# MyCloudConfig RFCs

This repository contains Request for Comments (RFC) documents for the MyCloudConfig project.
RFCs describe architecture decisions, protocol specifications, design proposals, and long-term plans.

## Structure

Each document is stored as RFC-XXXX-title.md.

RFC numbers are sequential and fixed after publication.

RFC-0001 is the initial project plan.

## Purpose

The goal of this repository is to provide a transparent, versioned history of technical decisions and specifications that shape the MyCloudConfig ecosystem.

## Status

All documents represent proposals or specifications unless explicitly marked as deprecated or superseded.
